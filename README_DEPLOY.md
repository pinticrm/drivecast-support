# DriveCast Support Site

Bu paket App Store Connect için:
- Support URL
- Privacy Policy URL

sağlamak amacıyla hazırlanmıştır.

## En kolay yayınlama: GitHub Pages

1. GitHub'da yeni PUBLIC repo oluştur:
   `drivecast-support`

2. Bu ZIP içindeki dosyaları repo ANA DİZİNİNE yükle:
   - index.html
   - privacy.html

3. Repo > Settings > Pages

4. Build and deployment:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
   - Save

5. Repo `pinticrm/drivecast-support` ise URL'ler:
   Support:
   https://pinticrm.github.io/drivecast-support/

   Privacy:
   https://pinticrm.github.io/drivecast-support/privacy.html

6. URL'lerin herkese açık şekilde açıldığını kontrol etmeden App Store Connect'e yapıştırma.

## App Store Connect
Support URL:
https://pinticrm.github.io/drivecast-support/

App Privacy > Privacy Policy URL:
https://pinticrm.github.io/drivecast-support/privacy.html
